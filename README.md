## What I Build

[**SwiftCache**](https://github.com/krishnaZawar/SwiftCache) — Redis-inspired in-memory database in C++, featuring custom hash tables, incremental rehashing, AOF persistence, key expiration, handling millions of keys effectively.

[**LevelCraft**](https://github.com/krishnaZawar/LevelCraft) — No-code game engine and builder built around component-based architecture, event-driven simulation, generic input handling, and runtime game construction, designed to let users build and run games without writing code.

[**Distributed Logger**](https://github.com/krishnaZawar/distributed-logger) — Go-based centralized logging pipeline with persistent offsets, acknowledgement-based consumption, contextual enrichment, and at-least-once delivery semantics, providing reliable centralized log collection for distributed services.

[**Custom Interpreter**](https://github.com/krishnaZawar/interpreter) — C++ interpreter with custom parsing and execution infrastructure, providing a complete pipeline from source code to runtime evaluation.
